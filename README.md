# egger-dekorok

Egger decor board photos (1920px) used as textures by the butorterv-viewer 3D kitchen viewer (served over jsDelivr CDN). Source: egger.com public decor catalogue.

Kaindl decor photos (`kaindl_<code>.jpg`, 700 px): the Detail images from the Jafholz product pages, each about 500 x 500 mm of the board (Kaindl names the matching files `_50x50`), grain vertical.
